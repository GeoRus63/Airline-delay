# 搬迁到另一台电脑 / Move to another computer

本页是当前迁移说明。旧版研究已在本机完成 P0–P7；原结果使用 2024 年 B-43 主映射，尚未采用本地已有、覆盖更好的 2025 参考表重跑。当前暂不重训、暂停视频处理。封存版的具体运行身份、参数与历史命令见[最终运行说明](最终运行说明.md)；当前待办见[执行进度](执行进度.md)。

## 克隆和输入检查

在 PowerShell 7 中保留完整 Git 历史，不使用 `--depth 1`：

```powershell
git clone --branch codex/apr-aug-research https://github.com/GeoRus63/Airline-delay.git airline_delay
Set-Location airline_delay
python scripts/verify_downloads.py --raw-only
```

原始航班、天气和 B-43 档案已存入仓库，保持相对目录结构；来源与哈希见 `sources.json` 和 `tables/file_manifest.json`。`.gitattributes` 保留原始字节。`--raw-only` 检查原始文件大小、SHA-256 及压缩完整性，不联网、不训练、不解析测试目标。无该参数的早期快照核验可能因后续合法源码改动出现差异。

选模登记协议和历史源码审计依赖完整 Git 历史；已有浅克隆应先执行 `git fetch --unshallow`。不要用下载仓库 ZIP 替代需要历史证据的迁移。

## 重建实际环境

已运行的项目环境是 **Python 3.13.15**，不是早期文档建议的 3.12。`requirements.txt` 固定直接依赖，`requirements.lock.txt` 是实际完整依赖清单。同平台、同解释器版本优先用 lock；不要复制旧 `.venv`，也不要覆盖目标机已有环境。

新副本尚无 `.venv` 时，用已安装的 Python 3.13.15 创建：

```powershell
# 将路径替换为目标机的 Python 3.13.15 解释器。
$Python313 = 'C:/Path/To/Python313/python.exe'
& $Python313 -m venv .venv
$ProjectPython = Join-Path (Get-Location) '.venv/Scripts/python.exe'
& $ProjectPython -m pip install -r requirements.lock.txt
& $ProjectPython --version
& $ProjectPython -m pip check
```

本次 lock 包含 Windows 依赖；换平台或版本需要记录新环境并验证数值，不能预先宣称等价。报告/PPT 渲染使用独立 artifact runtime，环境细节见封存版最终运行说明。模型不需要 GPU。

| 原电脑同步或独立副本重建 | processed、各 run 的 data、生成参考表等 | 按原清单和收据核验完整性 |

Release 下载、解压和 SHA-256 校验见[模型与预测归档](模型与预测归档.md)及[清单](../artifacts/model_prediction_manifest.json)。归档解压到项目根目录，恢复原 run 下的相对路径。另有 R0027 的两个解释样本预测文件已在 Git 中。模型与预测包不是全部计算备份。

完整迁移需保留 `processed/`、各 run `data/`、`references/taf_validity.csv` 等生成文件及冻结/ledger；按 manifest 和收据核验，而非仅看文件是否存在。部分历史归档固定绝对路径 `D:\airline-delay`，要求保持原身份的复现应恢复该路径；不能直接编辑封存 JSON 改路径。换路径重建需独立副本、新版本和新 run_id。

补齐后可执行只读归档审计，输出放在 run 档案外的新路径：

```powershell
& $ProjectPython scripts/verify_research_archive.py --all --output research/audits/NEW_MIGRATION_AUDIT.json
```

该入口不训练；缺少大型输入或产物时可能报告不完整。不能把克隆成功、下载包成功或环境检查通过等同于完整实验恢复。

## 恢复后的工作范围

先核对现有档案，不重新启动 `formal`，不删除正式账本，不覆盖 F0001 或已完成 run。不要直接重跑准备脚本覆盖现有 `processed/` 和生成参考表。需要重建时，遵守[完整执行流程](Codex完整执行流程.md)与[项目计划](完整项目计划.md)，在独立副本使用新数据版本、配置和 run_id。

2025 飞机参考表已在本地，覆盖更好；后续需核实航司/尾号身份与冲突，再更新 family/variant 并重跑。无法可靠补全的机型保留 unknown，航班仍保留。原报告和视频继续作为 2024 参考版档案；新版结果不能回填历史 run，已见 8 月不能再宣称是未见测试。

## 缺失原始文件时

正常迁移不需要重新下载。确有缺失时按 `sources.json` 取回相同原始字节，再核验清单；气象下载入口为 `scripts/download_data.py`、`scripts/download_taf_text.py` 和 `scripts/download_noaa_supplement.py`。BTS B-43 已保留原始 ZIP 及 2024/2025 两份年度参考表。下载脚本使用系统 `curl`，离线使用已有原始数据无需 curl。
