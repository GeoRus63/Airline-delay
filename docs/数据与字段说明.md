# 数据与字段说明 / Data and fields

## 原始数据

| 路径 | 内容与粒度 | 时间与连接方法 |
|---|---|---|
| `raw/flights/2026_MM.zip` | BTS Reporting 单航段，4–8 月 | AirportID、运营航司、机尾号、FlightDate；原始钟表时间是机场当地时间 |
| `raw/aircraft/bts_b43_all_years.zip` | BTS 年度飞机清单原始导出 | 运营航司＋标准化机尾号；2024 与 2025 参考表单独保留 |
| `raw/weather/metar/*.csv.gz` | IEM METAR/SPECI 原始观测，包括原始 METAR 文本 | `station`＋`valid`（UTC观测时刻） |
| `raw/weather/taf/*.csv.gz` | IEM TAF 预报分段 | `station`＋`product_id`＋`valid`（发布）＋`fx_valid`（分段开始） |
| `raw/weather/taf_text/*.zip` | 完整 TAF 原始报文 | 真实有效期、修订和取消信息；与分段通过 product_id 对应 |
| `raw/weather/noaa/*.psv.gz` | 缺日台站的 NOAA GHCNh 2026 年原始备用文件 | 台站＋DATE；保留原始变量、质量及来源码，目标电脑筛选4–8月 |

天气请求窗口为 **2026-03-30 00:00 UTC 至 2026-09-02 00:00 UTC（结束时刻不含）**，覆盖研究窗口及跨时区/预报提前发布缓冲。IEM 气象台站标识不一定等于航班 IATA：如 AZA 对应 IWA、ANC 对应 PANC；以 `references/airports.csv` 的对应关系为准。

IEM 实况风速/阵风为节，能见度为英里，云底为英尺，温度为华氏度。NOAA 同名天气量可能采用不同单位，按其原始文件表头和官方字典核对，不能直接拼列。两套资料可能转录同一份原始观测。

## 机场与机型参考

- `references/airports.csv`：355 个稳定 AirportID、当前显示代码、历史代码、ICAO、时区与气象站对应。坐标用于核对同址，不作为机场设施预测特征。
- `references/airport_codes.csv`：本研究窗口中观察到的机场代码与 AirportID。`first_date/last_date` 是本次航班中的出现范围，不是官方代码启用/停用日期。
- PBI 与 DJT 共用 AirportID 14027；连接按 ID，保留原始显示代码。
- `references/aircraft_reference_2024.csv`、`_2025.csv`：两份年度快照。仅提取机型用于预测；已有座位列不纳入模型。
- `references/aircraft_type_aliases.csv`：原始机型到系列、具体型号的显式规则。
- `references/aircraft_model_mapping.csv`：本研究航班实际匹配到的机型映射，原始标签另行保留。
- `references/aircraft_unmatched_tails.csv`：年度快照、月份、航司、机尾号的未匹配清单；不是独立飞机总数。

2025 年 B-43 清单于 2026-07-07 发布。主实验固定使用 2024 清单年份，2025 年份作覆盖对照；两者均是当前下载的年度资料，不是逐日历史机队快照。机型嵌套类别的编码策略见项目计划。

## 目标电脑生成的标准表

| 表 | 主要字段与用途 |
|---|---|
| `flights_clean.csv.gz` | 原始单航段，统一UTC、正常状态与时间有效标记；取消、备降记录保留 |
| `connection_candidates.csv.gz` | 同尾号计划时间排序后的相邻候选、各项筛选标志与首个排除原因 |
| `flight_connections.csv.gz` | 通过规则的同机衔接；RQ1/RQ2共用基础表 |
| `metar_observations.csv.gz` | `airport_id, weather_time, available_at`、风速/阵风、能见度、云底、降水/雷暴等 |
| `taf_bulletins.csv.gz` | 每次报文的发布时间、有效期、normal/cancelled/nil状态 |
| `taf_segments.csv.gz` | 每次报文内的主导、TEMPO、PROB分段，含有效区间及天气值 |

关键衔接字段：`upstream_arr_delay_minutes`（上游非负到达延误）、`downstream_dep_delay_minutes`（下游非负出发延误）、`scheduled_turnaround_minutes`（计划周转）、`delta_delay_minutes`（下游减上游）、`upstream_actual_arr_utc`（预测时刻）、`downstream_actual_dep_utc`（标签发生时刻）。实际地面时间与 delta 是事后分析字段，不作 RQ2 输入。

## 天气连接规则

METAR 按机场取预测前可用的最近观测。可用时间暂设观测后5分钟；观测距预测时刻不得超过120分钟，缺测保留缺失。未报告阵风/云底不自动填0。

TAF 先选择预测时刻已发布的最新报文，再在该报文中选覆盖查询时刻的分段；查询时刻取下游计划出发与 prediction_time 的较晚者。主导预报、TEMPO、PROB分别记录；IEM 的 `ftype=Observation` 表示开头的主导预报段，仍是预报。新报文取消或NIL时不回退旧报文；目标时刻不在有效期内时保留缺失。完整报文用于恢复 CSV 未给出的终止时间，不能一律假定24小时。

下载覆盖数表示有记录的机场/日期，不表示每小时无缺测，也不表示预报准确率。所有原始缺测和未提供TAF的机场均在交付覆盖表中保留。
