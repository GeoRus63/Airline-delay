# 飞机机型映射说明

本包用航班字段 `Reporting_Airline` 与 `Tail_Number`，分别匹配保存的 2024、2025 BTS Schedule B-43 清单。两年清单独立计算，2025 不回填 2026 年 4 月的历史预测视角。原始 `aircraft_model` 始终保留；显式映射表 `references/aircraft_type_aliases.csv` 维护 110 种本次航班实际观察到的原始标签，并额外列出参考清单中的 `B737-800` 明确别名。映射至 `aircraft_family` 和标准化后的 `aircraft_variant`。新出现的标签不会用字符串截断规则自动分类，脚本会要求先补入显式映射。

BTS 发布记录显示 2025 年 Schedule B-43 于 2026-07-07 加入；该晚于 2026 年 4 月，因此该版结果仅作并列的后见覆盖对照，不替代当时可用的 2024 快照。[BTS Release Info](https://transtats.bts.gov/releaseinfo.asp)

`aircraft_family` 使用系列口径：Boeing 737 Classic、NG、MAX 分开；A319/A320/A321 统一归入 Airbus A320 family ceo 或 neo；A330 ceo/neo 分开；A350 仅标为 Airbus A350，不使用 ceo/neo 称谓。`aircraft_variant` 在明确别名处统一写法，例如 `MAX8` → `737-8`、`B737-800` → `737-800`、`320-214` → `A320-214`；更具体的构型后缀保留在标准型号中，原字符串仍可从输出列 `aircraft_model` 追溯。

映射表的 `classification_basis` 说明归类依据；`source_url` 只在来源直接支持分类时填写。Boeing 737 家族使用 FAA 737 FSB 报告，A320 家族使用 EASA TCDS A.064。其他家族按 B-43 的原始型号代码保守归组，链接留空；[BTS B-43 字段说明](https://esubmit.rita.dot.gov/F41F-B-43.aspx)解释 `Type, Model and Cabin Design` 是原始型号来源，并不被当作各家族分类的认证依据。原始 `AA321-271NX` 标签未能无歧义解释，继续标为 `Unclassified`。

## 覆盖率与参考表

- `references/aircraft_model_mapping.csv`：仅包含实际匹配航班所涉及的原始机型，含原名、两层分类、依据和来源链接。
- `references/aircraft_monthly_match_rates.csv`：按参考清单年份和月份统计航班行匹配率、非空机尾号覆盖及唯一承运人/机尾号匹配数。航班行匹配率以该月全部航班行为分母。
- `references/aircraft_unmatched_tails.csv`：每个清单年份、月份未匹配到的非空承运人/机尾号组合。未匹配只表示该历史清单里没有相同键。
- `references/aircraft_reference_2024.csv` 与 `_2025.csv`：提取时保留 B-43 中机型非空但座位数缺失的行；座位数不参与机型匹配或覆盖率计算。

## 运行

```bash
python scripts/prepare_aircraft.py
```

脚本只读取其所在迁移包内相对路径的航班 ZIP、两份参考表与显式映射表，并将结果写入同一包的 `references/`；不下载 FAA 登记库，不训练模型或做性能测试。
